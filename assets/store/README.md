# Chrome Web Store screenshots

- [Light mode](screenshot-light.png): current-site toggle and saved sites.
- [Dark mode](screenshot-dark.png): adding the current site with optional access.

Both files are 1280x800, 24-bit RGB PNGs, with no alpha channel or transparency.
Upload them directly in the developer dashboard's Screenshots section.

The popup is rendered from the extension's actual HTML, CSS, and JavaScript with
representative tab states, placed alongside listing text. These images illustrate
the interface; they are not evidence of live website playback compatibility.
The icon is Lucide's human-designed Circle Fading Play artwork, with its license
included in `extension/THIRD_PARTY_NOTICES.txt`.
