# Icon source

The icon is [Circle Fading Play](https://lucide.dev/icons/circle-fading-play)
from Lucide. Its credited contributors are tatianatsiguleva, jordan808, jguddas,
colebemis, and karsa-mistmere.

The SVG was copied without changes from
[Lucide commit e00b2b2](https://github.com/lucide-icons/lucide/blob/e00b2b26350fe4dfb6f5273aa366f94974430903/icons/circle-fading-play.svg).
`scripts/icons.ts` renders PNG copies with indigo strokes and a transparent
background. The 128px copy includes additional padding for the store icon.
Regenerate the icons with `bun run icons`; builds also run this step.

Lucide's license is included in
[`extension/THIRD_PARTY_NOTICES.txt`](../extension/THIRD_PARTY_NOTICES.txt) and
ships in the extension ZIP.
